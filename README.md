# 결정제물함 v0.6

정적 HTML/CSS/JavaScript로 만든 개인 프로젝트 프로토타입입니다.

## 실행
`index.html`을 브라우저에서 열면 됩니다.

## 주요 변경
- 결과 공유 기능 제거
- 입력 패널과 제단 장면을 한 화면으로 통합
- SVG 기반 눈·제단 문양
- 제물 주시, 상승, 접힘, 소멸 애니메이션
- 촛불·입자·안개·화면 충격 연출
- 북소리, 우적우적, 종소리 Web Audio 합성
- 광고 자리 분리

## 배포 전
- 개인정보처리방침을 실제 광고/분석 도구에 맞게 수정
- 문의 수단 추가
- 도메인과 OG 이미지 점검
- 광고 심사 전 충분한 소개·콘텐츠 페이지 확보
